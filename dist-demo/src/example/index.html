Drawing Tools Plugin

A powerful drawing toolkit for Lightweight Charts™

Select a tool from the floating toolbar ↖

Trendline

Draw lines & channels

Click to set start point, move to end point, click again to finish. Drag points to resize or the line to move.

Fibonacci

Auto-calculated levels

Draw from swing low to high. Automatically shows 0.236, 0.382, 0.5, 0.618 levels with price labels.

Pen Tool

Freehand drawing

Click and hold to draw. Features smooth curves and pixel-perfect precision independent of candles.

Interaction

Select & Edit

Click any drawing to select it. Drag to move. Use the Eraser tool to delete.
